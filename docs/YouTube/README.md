# Cluster B
This folder has older Cluster B Personality disorder notes, mostly from 2023-2024 - pre-dating starting a degree. The information came almost entirely from YouTube, with the exception of a few (early) Chat GPT research notes. The Youtube videos were from professional Psychiatrists, Therapists and Psychologists, although just informal info-videos and lectures.

I bought and read chapters of the Middle Years book - a lot of Vaknin's videos focus on Psychodynamic theory and object-relations theory, with some associative learning.
